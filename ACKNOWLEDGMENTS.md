# Acknowledgments

Impresari Context is an independent implementation informed by publicly
demonstrated ideas from:

- LeanCTX, created by Yves Gugger and its contributors.
- Graft, created by Nanonets and its contributors.

We appreciate their work advancing compact and useful context for AI-assisted
software development. Impresari Context is not a fork, merger, official
successor, or endorsed project. No LeanCTX or Graft source code, tests, fixtures,
prompts, documentation, names, or visual assets have been incorporated.

See [Influences and provenance](docs/influences-and-provenance.md) for the
project's source-reuse and attribution policy.
