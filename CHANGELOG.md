# Changelog

All notable changes to Impresari Context are documented here. The project uses
[Semantic Versioning](https://semver.org/).

## [0.2.0] - Unreleased

### Added

- First-class, bounded client integration lifecycles for Codex, Claude Code,
  Cursor, GitHub Copilot CLI, and VS Code Copilot, with exact recorded client,
  operating-system, guidance, delivery, confirmation, and withdrawal scopes.
- Deterministic context planning with profile-bound requirements, explicit
  coverage and omissions, exact plan/packet identities, declared change sets,
  associated tests, repository orientation, convention exemplars, structural
  impact evidence, and incremental updates.
- Bounded structural evidence for Python, Rust, Go, Java, Kotlin, C#, C, C++,
  Ruby, PHP, Swift, Scala, Elixir, Clojure, Haskell, strict JSON, JSONC, TOML,
  and deliberately constrained YAML.
- Preview-first managed connection and native guidance installation, update,
  removal, doctor, quickstart, and checksum-verified installer workflows.
- Static-first hostile-repository artifact inventory, narrow execution-surface
  observations, unavailable-by-default analyzer coverage, normalized result
  intake, and deterministic admission policy without analyzer execution.
- A separate application-enforced synthetic analyzer supervisor plus exact-host
  Linux OS-confinement candidates for rootless user-manager and explicitly
  externally managed delegation profiles.
- A foreground loopback-only metadata dashboard with bounded live updates,
  one-use bootstrap, memory-only API-route capability, narrowing-only local
  budget policy, exact preview/apply/remove receipts, and explicit shutdown.

### Changed

- Workspace crates, runtime engine identity, structural resolver identity, and
  release-candidate packages now use version `0.2.0`; published `v0.1.0`
  artifacts remain the immutable rollback baseline.
- Release-candidate rehearsal now proves an actual `0.1.0` to `0.2.0` package
  upgrade and rollback instead of comparing two archives with the same version.
- Compatibility and product claims are exact-scope, expiring where applicable,
  and withdrawn on stale, changed, missing, unsupported, or unavailable state.

### Security

This candidate has not yet completed the independent human security review
required by ADR-0083 and ADR-0084. It must not be tagged or published as
`v0.2.0` until an attributable independent reviewer assesses the exact frozen
product commit, all blocking findings are resolved, and the separate release
gates pass. Automated, AI-assisted, native-platform, dependency, static-
analysis, fuzzing, packaging, checksum, and provenance checks are supporting
evidence, not a substitute for that review.

- External-client delivery remains explicit, exact-packet-bound, zero-tool or
  operator-confirmed as recorded, and uses existing authentication references
  in place without copying credential data.
- Repository bytes remain untrusted data and cannot add policy, network,
  credential, process, installation, publication, or orchestration authority.
- Linux IAR-1B evidence remains candidate-only; real analyzers, broad production
  support, privileged installation, persistent services, automatic repair,
  quarantine execution, and remote dashboards are not authorized.

## [0.1.0] - 2026-08-22

### Added

- A local-first Rust engine that builds compact, task-specific context packets
  from an exact repository snapshot.
- Verifiable source evidence, deterministic packet identity, explicit budget
  accounting, and visible completeness, exclusion, truncation, and staleness
  reporting.
- Read-only workspace discovery with protections for path traversal, symlink
  escape, hostile repository content, cache separation, and source mutation.
- Lexical retrieval for eligible UTF-8 files and structural analysis for
  TypeScript, TSX, JavaScript, JSX, Python, Go, Rust, and recognized strict-JSON
  configuration manifests. Other languages and JSON data files receive no
  structural support claim in this release.
- A command-line interface, neutral Rust library surface, reference client,
  consumer adapter contract, and local-only MCP server over standard I/O.
- Cross-platform CI, adversarial and conformance suites, release-candidate
  packaging, SBOM generation, dependency auditing, CodeQL, secret scanning,
  OpenSSF Scorecard, and bounded fuzz testing.

### Security

Security review status: This release has not undergone an independent
third-party security audit. It has passed the project's documented automated,
AI-assisted internal, native-platform, dependency, static-analysis,
secret-scanning, fuzzing, packaging, checksum, and provenance checks. These
controls reduce risk but are not a substitute for independent review.

- Repository content is always treated as untrusted data and receives no
  policy, execution, network, or orchestration authority.
- The initial release does not load executable extensions, grant privileged
  extension capabilities, provide remote MCP transport, or claim cryptographic
  signer identity for context packets.
- No publicly known vulnerability in Impresari Context is fixed by this first
  release.
